    新建 · 掉落物拾取

    1. 启用缓存检测 → 拾取 → 存入缓存
    2. 后台分类扫描缓存 → 识别分类 → 分批入库

    实验性功能，默认关闭。开启后，在拾取过程中 处理缓存容量不足，尝试装盒或分类腾出空间。 关闭后只执行普通拾取和存入缓存。

    按缓存箱已占用的槽位计算；达到阈值后尝试 装盒回存，需要空潜影盒供应。

    按所有缓存箱已占用的槽位计算，默认 80%。 打包优先会将投料装盒回存，盒子也放不下时再分类； 分类优先会先腾出缓存空间。装盒需要空潜影盒供应。

    在「坐标 → 区域 → 分类区」设置分类方式与储存范围。 拾取物存入缓存后才创建后台分类任务。

    拾取和存入全部完成后开始倒计时，期间可执行其他任务。
