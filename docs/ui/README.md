# 任务与坐标标准模板

直接打开 [settings-standard.html](settings-standard.html)。
这是唯一可运行的 HTML 模板，页面上方通过“任务／坐标”选项卡切换两种布局。

两个面板在同一文档中，切换时保留已填写的内容和展开状态。
右上角的浅绿／深灰主题同时作用于两个选项卡；支持键盘切换，隐藏面板不能获得焦点。
旧的任务、坐标两个独立 HTML 已删除。

[公共标准](settings-ui-standard.md) 说明选项卡、主题、控件和状态边界。
[项目提示词](task-ui-prompt.md) 保留业务字段和交互约定。
模板资源集中在 `shared/`；在仓库中直接打开 HTML 即可离线预览。

本次只修改模板及其规范和测试。正式页面、接口、任务执行、版本号和安装包均保持不变。
模板中的任务运行和资源保存只使用演示状态，不连接游戏。

`tests/test_single_settings_template.py` 验证单入口、选项卡切换、两侧草稿保留、
统一主题、键盘与焦点管理。原任务和坐标模板回归也已迁移到此入口。
运行测试和视觉验证仍遵守 `AGENTS.md` 与用户授权。
