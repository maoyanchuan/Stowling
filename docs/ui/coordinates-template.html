分类区 1

将展示物品与储存容器配对，并按识别规则自动分类。

分类区如何工作？

摆放方块、展示框、展示架和花盆内物品会自动转换为物品 ID， 与同一列储存容器精确匹配。长条分类架可框选总选区， 再填写多个母版分类物并设置方向、步长。
