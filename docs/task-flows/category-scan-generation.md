# 分类区扫描生成

流程标识：`category-scan-generation`。状态：**待验证**。
依据：用户提供的《Stowling 分类区扫描生成 · 一次性执行交接》（2026-11-28）。

## 输入、顺序与输出

1. 在坐标页选择分类区的“扫描生成”，输入总选区两个整数角点；反向角点等价。
2. 通过现有 Bearer 鉴权接口在客户端线程读取完整已加载选区的容器、箱体配对和标记。
   不导航、不开箱、不生成站位，不读取容器库存。
3. 仅以容器相对几何、种类、朝向和双箱关系寻找重复方向与间距，采用多数布局的
   一片作为母版。展示方块、展示框、盆栽及其占用情况不参与布局投票。
   无重复布局、并列且不能唯一确定、世界不可用或区块未加载时明确失败。
   当前复用现有储存容器范围：箱子、陷阱箱、木桶、漏斗和普通潜影盒。
   总选区最多 65536 格、256 片，单母版最多 4096 个图中构件与 256 组。
4. 单母版自动包含储存范围与候选展示位，支持在图中及详情中校正。
   展示位按单片画布的真实 X/Z 映射寻找箱侧、箱体两半上方或下方的相邻位置。
   箱侧保留同高／高一格候选，也允许低一格的展示；上位越出总选区时，不丢弃仍在选区内
   的同高有效标记。候选区域不得占用储存箱体，不因箱子朝向而漏掉画布中的相邻位置。
   现场展示物的坐标和已有手动排除规则用于候选评分，最终仍按用户确认的母版逐片核对。
5. 确认母版时重新读取世界，按修改后的几何和绑定逐片核对。
   按展示框真实朝向排除本处支撑，盆栽使用已有植物映射；不全区忽略支撑材料 ID。
   某片缺箱、单双箱不同、容器错位、缺少标记或标记归属冲突时报告片号、坐标和差异，
   整片跳过，后续片位置不前移。有效片的各组映射到本片真实容器。
6. 应用结果后方可保存。保存再次按最终母版核对，持久化一张母版、每片结果及有效绑定。
   重开和再次保存保留异常片空缺。总选区变化后旧扫描失效，须重新扫描。

## 完成、失败与中断

至少一片有效并成功写入配置才算完成。全部异常时保留可校正母版，拒绝保存。
放弃或请求失败保留原资源；过期请求不得覆盖新的选区、所选资源或草稿。
扫描没有任务运行、背包或世界修改，无需任务中断收尾；离开时沿用坐标页草稿确认。

## 数据与主流程边界

扫描配置与旧 `expansion` 互斥；母版单独保存，不能从有效绑定的头部反推母版。
有效绑定按完整片生成，不使用旧自动铺满填补缺口。既有分类解析仍读取各片自己的标记，
用户的排除、重复判定和多物品绑定沿用原语义。自动支撑排除仅作用于现场关系。
预览与任务读取共用总选区的标记快照坐标，再按各片候选区过滤，避免边界展示框被换算到
不同支撑坐标。任务仍只读取有效片；母版的具体展示物 ID 不复制到其他片。
图中方块与区域标注分别维护；移动图中方块不会代替重新绘制识别区，最终确认会重读现场。
现有手动分类、执行顺序、站位导航、开箱存取、打包、溢出及收尾主流程不变。
本功能是用户主动选择的坐标配置生成方式，默认仍为手动配置；无新增任务调试开关。

## 展示容器与支撑上的展示物

状态：**待验证**。用户确认图 2 新增位置是同一储存箱的候选展示位置，最终仍对应一个物品。
现场示例：`(216,-23,-20)` 属于朝北的储存双箱；`(216,-24,-20)` 是朝东的单箱展示物，
即使为空也识别箱子本身，不读取库存，也不作为额外储存容器。
相邻片的 `(222,-24,-73)` 展示去皮诡异菌丝，`(222,-24,-74)` 使用石英块支撑
`(222,-23,-74)` 的橡木压力板，后一片识别压力板，并按现场关系排除该处石英支撑。

扫描须区分物理容器与母版声明的储存角色。重复结构用于推断储存骨架，展示容器的变化
不能改变分片；最终仅允许母版候选展示位中的容器充当展示物，其余多余容器仍报错。
多数结构不足以分清角色时保留歧义，不以空箱、单箱或容器 ID 直接决定储存角色。
展示框按真实附着方向、盆栽与压力板按有效下方支撑，关联到同一逻辑展示位。
保留真实展示物坐标及 ID，已有坐标排除仍针对真实标记；不全区忽略石英或其他支撑 ID。
母版保存逻辑展示位及包含实际候选的识别范围，手动重画后以新范围为准，重新读取现场。
候选分配须跨组核对，不能把同一展示位自动分给相邻两个组；无法唯一归属仍整片跳过。
仅扫描配置使用这些规则，旧手动配置和任务导航、开箱、存取、打包、收尾不变。
无新增任务调试开关，也不增加“空容器自动读取本体”的库存识别回退策略。

实现版本：`alpha.342`。储存角色从母版 `storageArea` 计算；物理容器仍保留在图中，
位于声明展示范围的容器不参与储存布局差异。逻辑展示位使用 `scan.markerAnchors`，
每个组对应一个或多个候选坐标；读取世界时仍保留物品实际坐标及支撑关系。
根据重复结构与候选覆盖推断并跨组分配，等价分配保留歧义供用户校正，不按物品 ID 决定母版。
旧扫描配置缺少该字段时继续按已保存范围读取；新扫描建议重新生成母版。
编辑识别范围会清除本组旧位置关联，保存与确认均重新读取世界，不沿用旧分类结果。
