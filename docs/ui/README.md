# 任务设置标准样板

直接用浏览器打开 `task-settings-standard.html`，无需启动游戏或安装依赖。

- 右上角可以切换浅绿、深灰主题，颜色取自项目的 `workbench.css`。
- 设置行、开关、下拉框、数字输入和子设置均可交互。
- 示例状态和主题保存在浏览器本地，与真实任务配置分开。
- 本页仅用于界面调整，不连接控制台接口，不执行游戏任务。

后续先在这个样板中确认布局和交互，再将认可的组件接入正式任务页。
所有尺寸集中在 `#stowling-settings-standard` 的 CSS 自定义属性中；
配色使用项目原有的主题变量，调整布局时保留两套主题的颜色约定。

`tests/test_task_settings_sample.py` 覆盖主题与项目一致、离线资源完整、
标签和折叠控件引用完整，以及不依赖聊天宿主和游戏服务。
按项目规定，这些测试仅在用户要求时运行。
