# Stowling 任务 UI 项目提示词

你正在维护 Stowling 的任务界面。用户已经确认一份标准模板。
处理任务 UI 时，应复用该模板的结构、配色和交互，而不是重新设计一套界面。
本轮用户的明确要求优先于模板；仅调整用户要求的范围。

## 开始前读取

先从项目根目录读取以下文件，再确定实际生效的页面、脚本和样式：

1. `AGENTS.md`：项目规范、测试授权与交付要求。
2. `docs/ui/task-settings-standard.html`：唯一可运行的任务 UI 模板。
3. 本提示词：模板的语义和不可遗漏的交互要求。
4. `src/main/resources/stowling-web/workbench.css`：当前项目主题与共用样式。
5. `src/main/resources/stowling-web/settings-ui.js` 及本次涉及的任务页面和脚本。

模板保存在仓库中，可以离线打开。不要依赖聊天附件、临时截图或本机预览端口。
已有测试只能证明其实际覆盖的行为，不能据此宣称界面已与模板视觉一致。

正式坐标页面 `coordinates.html` 直接使用 `coordinate-management-standard.html` 的双栏结构。
坐标模板的左栏整条用于坐标展示：列表填满标题、操作按钮与底部统计之间的剩余高度，
随右侧编辑区拉伸到底，不再限制为 360px 的小展示区；内容超出时仅在列表内滚动。
列表条目保持自然高度并从顶部排列，不能为填满左栏而拉高单个文件夹或坐标项。
760px 及以下继续上下排列，列表随内容自然展开，不恢复 250px 的高度上限。
其生效样式与脚本为 `coordinate-editor.css`、`coordinate-editor.js` 和
`coordinate-editor-model.js`；维护坐标页面时也必须读取这些文件。
通过 `common.js` 的鉴权请求连接 `/v1/coordinate-resources` 和已有资源接口，
不得恢复模板示例数据或仅保存在内存中的演示操作。
坐标编辑区完整采用模板，只提供坐标点、区域、分类区三种类型。
不保留旧版的组合储存区、储存区成员、搜索、重新读取或额外设置行。
真实后端资源使用模板已有控件承载，不以兼容旧功能为由扩充编辑区。
绑定组标题中的名称输入框必须可编辑，并随分类区保存、复制和自动拓展保留。
标题按模板从左到右排列展开箭头、名称，右侧放绑定组的“独立设置”开关。
“删除此组”放在组展开内容的底部，收起时隐藏，避免标题区域误触删除。
不继承旧样式的两端对齐或附加箭头；组展开箭头与独立设置开关分别维护状态。
分类区选项行上下保留 10px、左右保留 12px 内边距，让悬停背景与文字、控件留出空间。
子选项在左侧基础留白上再缩进 18px；480px 及以下取消额外缩进，仍保留 12px 留白。
各行控件右边缘保持对齐，悬停背景上下内收 4px，悬停时不得移动内容。

### 坐标分类区的全局与绑定组设置

- 总选区下方保留全局的储存模式、识别模式、储存方式、忽略支撑方块和指定站立位置设置。
- 坐标模板的“支撑方块”使用多行文本框，每行填写一个方块 ID，允许填写多种方块，
  不沿用单行输入的 80 字符总长度限制。全局与绑定组独立设置使用相同控件，
  保持主题、右侧对齐和 reveal 动画；Enter 用于换行，不提交表单。
  关闭、收起、保存和复制时保留完整的多行草稿，首次开启独立设置继承全局值。
- 坐标模板在“忽略支撑方块”及其子项下方提供“指定站立位置”开关，默认关闭。
  标签下方以辅助说明小字显示“填写站立脚下方块坐标”，全局与绑定组独立设置保持一致。
  开启后按现有 reveal 动画展开 X／Y／Z 整数坐标输入；展开箭头与开关分别维护状态。
  关闭、收起、保存或复制时保留坐标草稿；各绑定组的独立设置中提供相同控件。
  正式页面将 `specifyStanding` 与 `standingPosition` 保存到全局及组内 `categoryOptions`，
  `standingPosition` 保留脚下方块坐标；生成单点 `standingArea` 时将 Y 加 1，
  作为玩家脚部坐标接入寻路与到达判定。读取已有配置时修正同类站位的高度，
  保留单片拓展的水平偏移；关闭时清除生效站位并保留草稿。
  单片拓展沿用现有站位平移逻辑；旧数据缺少新字段时保留原站位区域。
- 坐标模板选择“散货盒子混合储存”后，在其子菜单中显示“散货占比”，
  默认显示 27/54 组，前面的组数可输入 0 到 54 的整数，分母固定为 54 组。
  其他储存方式下收起此项并保留数值；绑定组首次启用独立设置时继承当前全局值，
  之后独立编辑，保存和复制保留数值。正式页面使用全局及组内 `categoryOptions.bulkStacks`
  保存数值，并将生效值写入 `storagePolicy.looseSlots`，接入现有混合储存执行逻辑。
  明确设置散货占比后优先保留配额内散货，只打包超额散货；允许原有或新建的盒子不满，
  不沿用旧的“仅满盒”限制来借走配额内散货凑满盒。已保存配置在读取时采用同一规则。
  旧数据优先读取 `looseSlots`，缺少时按原有 `loosePercent` 换算为 54 格的组数。
- 每个绑定组默认关闭“独立设置”，使用上方全局配置；组内识别区和储存区仍可编辑。
- 开关旁的标签始终为“独立设置”；开关开启表示使用该组配置，关闭表示使用全局配置。
  不随开关状态把标签改为“使用全局设置”，避免混淆开关控制的功能。
- 开启独立设置后，在该组内部展开相同的配置，以及它们已有的相关子选项。
  首次开启时以当前全局值初始化，此后各组独立编辑，不能互相覆盖或反写全局。
- 关闭独立设置时收起配置区并恢复使用全局值，但保留该组已填的独立配置。
  再次开启、保存、复制和重新选择资源时，保留独立设置开关与各组配置值。
- 绑定组展开状态与独立设置开关分离；切换独立设置不得折叠整组或改变区域坐标。
- 全局和组内设置复用控件样式及交互，包含键盘导航、选中勾号和上下展开。
  绑定组常态允许菜单溢出，只有 reveal 动画期间临时裁切，避免子菜单被卡片遮挡。
- 以上规则以坐标模板为准；移植到正式页面时必须接入真实保存与执行逻辑。
- 正式数据用分类区的 `categoryOptions` 保存全局配置，绑定组的 `optionsEnabled` 和
  `categoryOptions` 保存独立开关及草稿；接口和配置文件校验均须支持这些字段。
  实际识别与储存字段由生效配置生成，关闭独立设置时也不得丢弃草稿。
- 单片与选区模式混用时，只拓展生效配置为单片模式的绑定组，选区组保留一次。
- 总选区通过 `overallArea` 独立保存，不因切换为选区模式或关闭独立设置而缩小或丢失。

### 分类标记与多物品绑定预览（待用户确认）

- 本轮仅扩展 `coordinate-management-standard.html` 模板，正式页面与游戏逻辑暂不接入。
  模板默认选中“花簇与幽匿分类（示例）”，坐标与物品清单均为展示数据。
- 在“忽略支撑方块”下方增加“按坐标排除标记”、“忽略重复方块”和“多物品绑定”，
  全局与绑定组独立设置复用同一控件，保持浅绿／深灰主题和现有设置行布局。
- 按坐标排除使用可增删的 X／Y／Z 行，只跳过该位置的自动标记识别，
  不排除其他位置的同类方块，不禁止物品入库，也不使指定容器失效。
- 多物品绑定使用可增删、可命名的规则，每条规则包含绑定目标和每行一个 ID 的物品清单。
  绑定目标有三种：识别物 ID（作用范围内同类标记）、标记坐标（指定位置的标记）、
  容器坐标（当前储存区内的指定容器）。切换目标类型时保留其他类型的输入草稿。
- 每条已有物品绑定规则默认收起，只显示展开箭头、可编辑名称和物品数量；
  点开子菜单后显示目标与物品清单，“删除规则”放在展开内容底部。
  新增规则直接展开，规则子菜单互不影响，收起不关闭多物品绑定开关。
  子菜单使用现有 200／150ms reveal 动画，保存与复制保留当前展开状态及草稿。
- “忽略重复方块”默认关闭，示例分类区开启以展示开关状态，判定说明默认收起。
  开关与说明的展开箭头分别维护状态，全局与组内独立设置均保存 `ignoreRepeatedBlocks`。
  先应用方块 ID 与坐标排除，再从同一分类区原本只有一种摆放方块标记的单片收集参照。
  仅对多物品冲突的单片排除有独立参照的重复方块，且只在剩余一种物品时采用结果；
  原始独立分类仍保留，没有参照、剩余零种或多种时继续提示冲突。
  不使用本轮推断结果扩充参照，不因扫描顺序产生连锁排除，最后再追加多物品绑定。
  珊瑚扇与平滑石英台阶作为说明示例，此模板尚不执行游戏世界的重复方块判定。
- 绑定物品追加到目标原有分类，各物品仍按自己的 ID 入库；规则作用于当前分类区，
  开启组内独立设置时使用该组规则。排除的标记坐标不能再作为标记绑定目标，
  同一坐标作为容器目标时不受标记排除影响。
- 开关与展开状态分离，沿用 200／150ms reveal 动画及下拉选中勾号、键盘与上下展开。
  关闭、收起、保存、复制和重新选择资源时保留列表与多行草稿；
  首次开启组内独立设置复制全局配置，后续编辑互不覆盖。
- 模板草稿字段为 `ignoreMarkerPositions`、`ignoredMarkerPositions`、
  `ignoreRepeatedBlocks`、`multiItemBindingsEnabled`、`multiItemBindings`；
  规则的 `expanded` 仅保存编辑子菜单状态，规则同时保存名称、目标类型、标记 ID、
  坐标与多行物品 ID 文本。此处记录预览约定，后续正式接入仍需对接真实数据与业务逻辑。

## 模板适用范围

任务页中的模块卡片、标题栏、任务开关、设置行、子设置、下拉框和数字输入均适用。
后端执行、任务字段、接口、保存方式和鉴权沿用项目现有实现。

“移动到坐标”只提供目标坐标和运行优先级，不添加“中断与收尾设置”。
旧移动任务再次保存时清除原存放位置和保留进度设置。

“自动进食”提供任务优先级，作用于进食任务和对应的饱食度监听器。
自动补给使用开关和独立展开箭头，子菜单包含食物箱坐标、拿取数量、
“优先吃身上的食物”开关；拿取后默认锁定自用，不另加锁定开关。
默认拿取 64 个，优先吃身上锁定的指定食物；关闭优先开关后，每次任务先补给再进食。
关闭自动补给时只吃身上锁定的指定食物，保留坐标、拿取数量和优先开关的草稿。
自动进食底部只保留删除任务，展开与收起统一使用标题栏箭头，不再放“关闭”按钮。

“刷新缓存”的选区控件只保留下拉选择框，不显示“去坐标页添加”链接。
容器类型使用共用样式绘制的单个展开箭头，不在箭头内再叠加 SVG。

“分类”任务的来源位置统一标为“物品来源”，拾取任务继续使用“缓存位置”。
分类目标统一标为“目标分类区”，使用一行多选下拉，提示使用“请选择目标分类区”。
直接勾选或取消坐标页已有的分类区，不提供添加按钮、逐项折叠层或单独的移除按钮。
少量选择显示名称，超过两个显示“已选 N 个分类区”，完整名称在控件提示中保留。
多个目标在下方按执行顺序展示；旧任务保留已存顺序，新勾选追加到末尾，取消则移除。
刷新资源、保存、重新打开或切换开关不得按资源目录顺序重排目标。
已删除的目标保留已选状态与失效提示，允许直接取消，不静默移除或替换。
空列表提示先到坐标页配置；共用下拉的主题、选中勾号、间距、键盘和上下展开保持一致。
资源失效提示和前后端校验使用相同术语，不再使用“来源缓存”或“分类选区”。
“分类”任务及旧版自动分类任务的目标分类区只引用坐标页面的分类区，不再提供任务级
“储存模式”。储存模式及相关选项统一使用所选分类区的全局或绑定组独立设置，
不得复制第一组配置到任务；旧任务中的 `storagePolicy` 仅兼容读取，不再使用或保存。

“分类”任务主设置提供“空盒仓库”开关与独立展开箭头，启用后选择坐标点或容器区域。
子设置包含“缓存留存空盒”开关与独立展开箭头，启用留存后填写保留数量，默认 9 个。
“空盒仓库”和“缓存留存空盒”的容器均不绘制底部分隔线，沿用模板的留白层级。
关闭或收起时保留仓库、留存开关与数量草稿；任务运行状态和配置展开状态分别维护。
设置保存到 `cleanupPolicy.emptyBoxWarehouse`，包含 `enabled`、`warehouseRef`、
`retainInCache` 和 `cacheLimit`。旧的点位供应配置保留兼容读取。
启用仓库后优先取用缓存空盒，不足从仓库取；关闭留存时多余空盒归仓，开启留存时
物品来源内的所有容器合计保留至上限，超额归仓，不主动从仓库搬盒补足留存数量。
关闭仓库时只在缓存内取用和回收。分类任务不再显示收尾设置内的旧空盒供应点位选择。

“售卖弹性物资”“四号谷地”“武陵”及模板数值只是排版示例。
不得将这些示例名称、虚构选项或样板的本地存储方式移植为正式任务业务逻辑。
正式任务开关必须接入该任务已有的开始／关闭接口；不得仅改变本地外观冒充执行。

## 标题栏与开关语义

- 左侧只保留一个小图标和任务名称，不恢复拖动柄或标题前的勾选框。
- 右侧依次放置展开箭头、任务开始／关闭开关，两者独立操作。
- 展开箭头只控制设置区的展开与收起，不改变任务运行状态。
- 任务开关只控制任务开始／关闭，不禁用整个配置区、不改变展开状态、不清空数值。
- 关闭任务后仍能编辑设置；运行状态和配置状态必须分别维护。
- 各子功能自己的开关仅影响该功能；不得与任务运行开关共用状态。
- 保留可访问名称、展开状态、关联区域和任务运行反馈。

## 布局与主题

- 复用项目的浅绿和深灰主题变量，两套主题使用相同结构与交互。
- 颜色以当前 `workbench.css` 为准，不额外创造与项目不一致的配色。
- 模板内的主题颜色是离线快照；项目正式主题变更时同步更新快照与相关用例。
- 设置行左侧为标签或标签加说明，右侧为控件；同类控件右边缘对齐。
- 设置项名称与分组标题使用主文字色 `--text`，保证清晰度；辅助说明才使用 `--muted`。
- 鼠标悬停时整行高亮，底色随主题变化，文字和控件不因悬停发生位移。
- 高亮只使用一个整行背景层，保留两侧 10px 圆角；子容器不得裁切外扩的高亮，
  行内按钮不再叠加矩形高亮。普通行与“中断与收尾设置”在常态下均无独立底色或卡片。
- 子设置在所属行下方展开，用适度缩进、说明和数值单位表达层级。
- 不把每个设置行再包进一张独立卡片，不以追加多层 CSS 覆盖代替修改原有规则。
- 控件、标签、说明和弹出菜单在窄窗口下必须完整显示，可换行或改为上下排列。
- 任务条收起后必须保留完整的底部圆角；展开时标题下缘与设置区平整衔接。
  不得通过裁切整个卡片来恢复圆角，以免下拉菜单被截断。
- 左侧高亮条在卡片内用独立装饰层绘制，沿卡片内圆角裁切自身背景。
  不使用加粗的左边框，不形成突出的外轮廓或第二层错位圆角；保留现有内容对齐。

桌面基准尺寸集中在 HTML 中 `#stowling-settings-standard` 的 CSS 自定义属性：

| 项目 | 当前模板值 |
| --- | --- |
| 标题栏最小高度 | 70px |
| 普通设置行最小高度 | 82px |
| 左右内边距 | 20px |
| 设置文字 | 16px |
| 输入控件高度 | 42px |
| 开关尺寸 | 56px × 32px |
| 下拉控件区域宽度 | 38%，同时遵守模板最小宽度与窄屏规则 |
| 数字输入框宽度 | 56%，窄屏可占整行 |
| 卡片圆角 | 使用项目 `--radius`，随主题变化 |
| 左侧高亮条 | 5px，位于卡片圆角内侧 |

这些值是复现模板的默认值；适配实际容器时保留其层级和对齐关系，不机械缩放整页。

## 主菜单、子菜单与下拉选项

- 主任务设置区、各子设置区都要有展开和收起动画，不能只给子菜单加动画。
- 使用模板的 `reveal` 思路：展开 200ms、收起 150ms，
  缓动为 `cubic-bezier(0.16, 1, 0.3, 1)`。
- 动画过程中平滑改变可见高度与透明度，收起完成后再隐藏内容。
  不在点击时直接用 `hidden` 跳过动画。
- 外层承载可收至零高度的动画，内层承载内容内边距，避免结束时突然跳动。
- 坐标子选项由共用 reveal 在首次使用时包裹无内边距的动画外层，
  高度动画只作用于外层，保留内层设置行的最小高度、内边距和控件尺寸。
  不直接压缩带内边距的设置行，避免收起末段停留在内边距高度后突然消失。
  绑定组的相关间距放入展开内容内部一同收起，不在隐藏时突然移除父级 gap。
- 初次载入不播放展开动画；快速反复点击时取消旧动画，旧回调不得隐藏重新打开的内容。
- 尊重系统减少动态效果的设置；隐藏内容不可通过键盘意外聚焦。
- 下拉选项使用统一主题、用途说明和选中勾号，选中状态与鼠标悬停状态清楚区分。
- 必选资源的“请选择……”只作为未选择时的控件提示，不出现在展开的选项列表中；
  保留底层空值与必填校验，不自动替用户选中第一项。“不指定”等有效空值选项仍保留。
- 选项之间保留 6px 间距；未选中项的悬停底色比选中底色更淡，不连成一整块高亮。
- 下拉菜单不得被卡片裁切，宽度适配窗口；下方空间不足时向上展开。
- 支持方向键导航、Enter／空格选择、Escape 关闭、Tab 离开和点击外部关闭。
  选择完成或按 Escape 后，焦点回到触发控件。
- 折叠、切换策略、关闭子功能或开始／关闭任务时，保留已有配置值。
