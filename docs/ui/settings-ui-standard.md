# 任务与坐标共用 UI 标准

唯一可运行入口是 [settings-standard.html](settings-standard.html)。
模板在同一文档中提供“任务”和“坐标”两个选项卡，分别展示任务卡片和坐标双栏布局。
本文件规定公共规则；`task-ui-prompt.md` 继续记录正式业务字段和状态约定。

## 选项卡与面板

- 选项卡位于页头下方、面板内容之前，导航条占满正文宽度，与左右内容对齐。
  外观参照正式页面的 `workspace-nav`：最小高度 46px、内边距 5px、间距 6px、
  外圆角 11px；标签使用 13px 加粗文字、9px × 18px 内边距和 7px 圆角。
  普通标签透明，选中与悬停使用独立背景层；沿用正式导航的悬停、按下和选中动效，
  减少动态效果时关闭动画。540px 及以下标签等分可用宽度，触摸设备保留 44px 点击高度。
  仅保留模板已有的“任务／坐标”面板入口，不添加没有对应面板的正式页面导航项。
- 默认打开“任务”，也可用 `#task`、`#coordinates` 直接打开对应选项卡。
- 两个面板只初始化一次；切换只改变显示与焦点状态，不重建表单，不丢失草稿、
  已选资源、功能开关、运行模拟状态和展开偏好。
- 页头沿用正式页面的图标、标题和副标题排列，不再放置额外的模板大标题。
  页头使用正常行高、18px／14px 上下内边距；标题与副标题间隔 0.15rem，图标间距 0.9rem。
  页头到导航保留 14px，导航到面板保留 32px，包含正式页面网格间距与导航下边距的总留白。
  副标题随当前选项卡显示任务管理或坐标管理；右侧显示主题按钮与“离线预览”状态，
  不将模板标为已连接游戏服务。
- 页面只提供一个“主题：浅绿／深灰”切换按钮，点击在两种主题之间切换；
  按钮文字显示当前主题，提示说明下一次点击的目标。切换立即作用于两个面板并保存偏好。
- 选项卡支持鼠标、左右方向键、Home／End。只有当前选项卡进入 Tab 顺序；
  非活动面板同时设置 `hidden` 与 `inert`，不能获取键盘焦点。
- 切换时关闭当前展开的下拉菜单，重新进入后保持原有选值。
- 两部分直接合并在一个 HTML 的两个面板中，不使用 iframe 包装旧页面；
  删除 `task-settings-standard.html` 和 `coordinate-management-standard.html` 旧入口。

## 公共资源

以下文件位于 `docs/ui/shared/`，仅由离线模板引用：

| 文件 | 职责 |
| --- | --- |

| `settings-controls.css` | 设置行悬停层、开关、单选／多选下拉的公共样式和控件变量 |

| `task-template.css` | 任务面板布局，限定在任务组件内 |
| `task-console-template.css` | 任务面板的运行队列、任务进度、已保存任务及任务选择布局 |
| `task-console-template.js` | 售卖任务的离线队列、详情、日志及选择入口交互 |
| `coordinate-template.css` | 坐标面板布局，限定在坐标面板内 |
| `coordinate-scan-template.js` | 分类区扫描方式、示例预览与应用状态，仅供离线模板 |

| `coordinate-slice-plan.css` | 单片图的两种主题配色、方块侧栏与窄屏布局 |

模板通过相对路径加载公共样式和脚本；坐标模板继续引用已有的
`src/main/resources/stowling-web/category-standing-ui.js` 生成示例站位控件。
直接在仓库中打开 `settings-standard.html` 即可离线预览，不依赖游戏或临时预览端口。

本次只合并模板及其规范。正式页面、正式共享组件、API、配置和游戏执行均保持现状，
没有把上述公共模板资源接入 Mod，也不因此更新版本号或生成安装包。
后续移植到正式页面时，需单独明确接入范围，并重新验证真实数据与执行逻辑。

## 尺寸与布局

| 项目 | 任务 | 坐标 |
| --- | --- | --- |
| 面板最大宽度 | 1520px | 1520px，与正文和导航同宽 |
| 普通设置行最小高度 | 82px | 62px |
| 设置标签字号 | 16px | 13px |
| 常规输入与下拉高度 | 42px | 42px |
| 开关 | 56px × 32px | 56px × 32px |
| 下拉选项最小高度／间距 | 54px／6px | 54px／6px |

保留上述两种密度。任务卡片、左侧资源列表、坐标编辑器和绑定组属于页面布局，
不通过统一控件强行改成相同结构。任务左右留白、坐标一级缩进、760px 双栏换行
和 480px 控件换行等现有适配继续由各自页面样式负责。

坐标模板不再保留独立的 1220px 面板上限或 720px 编辑表单上限。
坐标双栏铺满正文，左栏保留原有宽度，右侧编辑表单占满编辑区可用宽度。
桌面窗口中，双栏至少填满页头、导航和页脚留白之外的剩余高度；
右侧内容较长时整页自然增长，左侧列表随两栏等高延伸、内容超出时内部滚动。
不通过拉高设置行、放大文字或控件来填满窗口。760px 及以下保留原有上下布局和自然高度。

公共控件变量使用 `--settings-*`；页面只覆盖声明过的尺寸或布局差异。
浅绿／深灰使用同一组件结构；普通状态透明，悬停使用一个圆角背景层，
不能因悬停移动标签或控件，也不能裁切菜单和高亮。

任务设置的子选项必须相对所属分组标题缩进，不能与标题左对齐。
缩进统一使用 `--sample-child-indent`：常规窗口为 20px，480px 及以下为 10px。
“单个物品最大售卖数量”下的“最大售卖数量”是子选项，遵守同一缩进要求。
整条子设置行或其内容容器承载缩进，保留输入框和其他控件的右边缘对齐；
不通过空格或只移动标签模拟缩进，已有子容器缩进时不再叠加一层。

## 任务控制台模板

- 桌面使用 270px 左栏和自适应右栏，间距 22px；左栏依次为运行队列、任务进度，
  右栏依次为已保存任务、任务选择。
- 已保存任务只保留原有的“售卖弹性物资”完整设置示例，不另建精简卡片或独立示例区。
  展开箭头和运行模拟开关分别维护状态，不因开始／关闭、刷新、切换面板或主题而互相重置。
  调试模式开关位于已保存任务标题右侧，只控制售卖任务实验选项能否编辑。
  “实验性设置”常驻、默认收起，调试关闭时也可展开查看；内部独立开关置灰禁用，
  调试开启后才可编辑。关闭调试不重置勾选值、草稿或展开状态，不改变任务运行状态。
  实验项 `experimental-example` 默认关闭，仅演示模板交互；已开启时显示生效标识，
  即使收起任务或关闭调试也可查看。此规则只调整离线模板，正式任务的调试显示保持原约定。
- 任务选择只提供“售卖弹性物资”入口，点击展开并聚焦现有任务，保留设置，不重复创建。
  清除掉落物拾取、分类、自动进食等其他任务示例及其队列、日志数据。
  队列、计数、运行详情和日志随模拟状态更新，日志支持导出和清空，空列表有明确提示。
  所有新增状态均为离线 UI 示例，不连接正式接口，不写入真实任务或执行配置。
- 左栏在桌面窗口中保持可见，队列与进度各自在内部滚动；1000px 以下左栏为 230px。
  780px 以下将任务工作区放在上方、队列与进度放在下方；540px 以下监控两栏改为上下排列。
  任务选择按工作区宽度显示四列、两列或一列，不以整页宽度挤压任务选项。

## 交互与状态

分类区“配置方式”沿用公共单选下拉，默认手动配置。扫描生成方式只要求总选区，
先预览示例摘要，再由用户应用；原配置在应用前保持，应用后可展开现有表单微调。
生成详情采用相同 reveal 动画，收起退出键盘焦点，展开状态与配置方式、草稿分别维护。
预览与总选区不一致时禁用应用，已应用配置与总选区不一致时禁用扫描方式的保存。
所有数据均为离线示例，不连接游戏，也不约定实际扫描算法；业务范围见项目提示词。
扫描坐标结果仅使用经典单片编辑器，预览与已应用布局共用同一张图。
固定 X，横轴 Z、纵轴 Y，隐藏轴标题、刻度与底部坐标读数，每格一个方块，双箱横占两格。
按选区取最多 15 列 × 10 行，超出时标注局部，仅绘制范围内的完整构件。
拖动或用方向键移动构件，落在空格后更新坐标，越界或重叠时归位，可撤销。
方块侧栏提供箱子、木桶、下半砖、楼梯。选中后点击空格放置，或用方向键选格后按回车。
侧栏可直接拖到空格，拖动预显落点；在占用格或画布外松手、取消手势时不放置。
点选已有方块后可点“删除方块”或按 Delete 删除。右键楼梯每次顺时针转 90°，四次回到原朝向。
删除和旋转支持撤销；保存、复制和应用保留删除状态与朝向。
新增或移动小箱子时，同一行左右贴边的两个小箱子合为双箱；两侧都有候选时先与左侧合并。
右键双箱或聚焦后按 Shift+F10，可在原地拆为两个独立小箱子；下次移动才重新判断合并。
添加、移动合并和拆分均可逐步撤销，箱型和占位随坐标草稿保存、复制和应用。
选区变化后保留只读快照。应用带入预览改动，放弃恢复已应用布局；保存与复制保留独立草稿。
背景、网格、文字和落点跟随浅绿／深灰主题；主题切换保留编辑位置。刷新恢复内置示例。
构件位置保存于 previewPieces／appliedPieces，绑定参数仍为独立离线示例，识别规则待接入。

- reveal 首次初始化不播放动画；展开 200ms，收起 150ms，
  使用 `cubic-bezier(0.16, 1, 0.3, 1)`。
  动画只裁切零内边距外层，完成后释放裁切；快速反向操作取消旧动画，
  旧回调不能隐藏重新打开的内容。减少动态效果时即时切换。
- 下拉支持方向键、Home／End、Enter／空格、Escape、Tab 和点击外部关闭。
  单选提交后返回触发控件；多选逐项切换且保持菜单打开。
  Escape 关闭并返回触发控件；Tab 关闭后继续正常焦点顺序。
  必选资源的空值提示不进入候选项，不自动选择第一项。
- 空间不足时向上展开，菜单高度限制在可用空间内；两个选项卡的菜单均使用行内定位。
- 隐藏或收起的内容退出键盘焦点。各组件独立维护展开状态，
  不因主题、运行、调试显示或其他组件操作而重置。
- 任务运行、功能启用、展开偏好、调试显示和配置草稿分别维护。
  分类区全局配置与绑定组独立草稿继续按既有字段保存。
  公共控件不能调用任务执行接口或向其他任务注入执行策略。

## 修改与验证

公共视觉或交互变化同步修改公共资源、本文件、项目提示词与相关用例；
业务字段变化沿用本标准，仅修改对应页面与业务约定。
不要再拆回两个模板入口，也不要复制另一份公共实现。

本次模板整合不改变任务主流程，不新增实验执行开关，不改变任何已保存执行值。
交互回归覆盖离线加载、主题、两种密度、键盘、多选、草稿保存与动画中断。
测试和视觉验证仍以 `AGENTS.md` 与本轮用户授权为准；游戏验证由用户执行。
