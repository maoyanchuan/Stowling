## 正常执行

1. 水平范围仍为指定方块范围；多个离散站位不连接成连续区域。
2. 脚部高度范围为脚下方块 Y + 1/16 至 Y + 1 + 1/8，另加 1e-5 浮点余量。
   统一覆盖下半砖、地毯、箱顶、灵魂沙和完整方块顶面，不逐种维护名单。
3. 寻路候选包含该高度带对应的整数脚部目标；到达和开箱共用范围判定。
   必须接地且水平速度不超过每 tick 0.03 格，真实交互距离和拾取避让仍需满足。
   尚未落稳时继续原导航或等待，不提前取消到站过程。
4. 重新对齐时不因当前脚部坐标而排除唯一指定站位。保留原有最多两次导航重试、
   间隔和容器访问超时，不自动换站位或无限等待。
5. 落稳后切换安全手持并开箱；切手期间再次核验。分类标记读取、目标存取和
   连续容器访问使用同一运行目标，存取仍按服务器确认量记账。

输出、完成、失败和中断条件沿用分类主流程：真实确认存取、清理任务账本及临时资源。
真实不可达、距离不足、超时或存取失败时沿用换箱、来源归还及中断收尾；
不把受阻当满箱，不改变原有任务最终成功状态的语义。
暂停、进食、取消和收尾继续使用同一轮冻结配置，并释放导航和容器资源。
