# 任务设置标准样板

直接用浏览器打开 `task-settings-standard.html`，无需启动游戏或安装依赖。

- 右上角可以切换浅绿、深灰主题，颜色取自项目的 `workbench.css`。
- 设置行、开关、下拉框、数字输入和子设置均可交互。
- 标题左侧仅保留图标与名称；右侧依次为展开箭头和任务开关。
- 任务开关仅模拟开始／关闭，不禁用配置、不改变展开状态，也不清空设置。
- 主任务菜单与子设置统一使用 200ms 展开、150ms 收起过渡；减少动态效果时直接切换。
- 下拉选项包含用途说明与选中标记，支持方向键、Enter、Escape 和点击外部关闭。
- 下拉选项之间保留 6px 间距，悬停底色比选中底色更淡，避免相邻高亮连成一块。
- 鼠标悬停在设置行时，整行显示与当前主题一致的背景高亮。
- 示例状态和主题保存在浏览器本地，与真实任务配置分开。
- 本页仅用于界面调整，不连接控制台接口，不执行游戏任务。

后续先在这个样板中确认布局和交互，再将认可的组件接入正式任务页。
所有尺寸集中在 `#stowling-settings-standard` 的 CSS 自定义属性中；
配色使用项目原有的主题变量，调整布局时保留两套主题的颜色约定。

`tests/test_task_settings_sample.py` 覆盖主题、离线资源、可访问标签和控件引用。
`tests/test_task_settings_sample_interactions.py` 覆盖任务与配置解耦、旧状态迁移、
下拉键盘操作、菜单弹出方向、动画中断和减少动态效果。
按项目规定，这些测试仅在用户要求时运行。
