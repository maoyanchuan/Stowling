后台条件

触发器状态

独立显示每个触发器的当前状态，即使没有运行任务 或等待队列也会持续更新。

等待队列

等待任务

任务按优先级进入统一队列。高优先级任务先执行 可配置的中断收尾，收尾完成后才让位；收尾失败时 队列暂停，必须先重试，或在确认导航停止并处理完 受管物品后跳过。
