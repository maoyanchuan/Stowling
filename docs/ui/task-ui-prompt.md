# Stowling 任务与坐标 UI 项目提示词

你正在维护 Stowling 的任务与坐标界面。唯一可运行模板通过“任务／坐标”选项卡切换两种布局。
处理 UI 时，复用公共主题、控件和交互，保留对应页面的结构与设置密度。
本轮用户的明确要求优先于模板；仅调整用户要求的范围。

## 开始前读取

先从项目根目录读取以下文件，再确定实际生效的页面、脚本和样式：

1. `AGENTS.md`：项目规范、测试授权与交付要求。
2. `docs/ui/settings-ui-standard.md`：唯一公共规范及资源职责。
3. `docs/ui/settings-standard.html`：唯一可运行模板，内含任务与坐标两个选项卡。
4. 本提示词：业务语义和不可遗漏的交互要求。
5. `docs/ui/shared/settings-theme.css`、`settings-controls.css`、
   `settings-controls.js`：模板共用配色、控件和交互实现。
6. `src/main/resources/stowling-web/workbench.css`、`settings-ui.js`
   及本次涉及的页面、脚本和样式。

模板保存在仓库中，可以离线打开。不要依赖聊天附件、临时截图或本机预览端口。
已有测试只能证明其实际覆盖的行为，不能据此宣称界面已与模板视觉一致。

### 坐标分类区的全局与绑定组设置

- 分类区在总选区上方提供“配置方式”标准下拉，默认“手动配置”，可选“扫描生成”。
  此入口只存在于离线模板，不新增识别模式或资源类型，不接入正式页面、API 或执行流程。
  扫描方式仅要求填写总选区两个角点，原基础设置、绑定组与站位收进生成详情，
  未应用前隐藏；切换方式保留当前草稿，不自动覆盖已有配置。
  “预览扫描示例”即时展示待应用摘要，明确标注离线示例，不模拟已连接游戏或真实扫描进度。
  示例包含基础设置、一个识别区与储存区绑定组及一个站位；实际可识别内容和规则尚未确认。
  用户点击“应用示例配置”后才替换当前基础设置、绑定组与站位，名称和总选区保持。
  生成详情默认收起，使用原有控件与 200／150ms reveal，展开后允许微调。
  空白或非整数坐标禁止预览；总选区变化时标记过期，禁止应用旧预览，
  扫描方式下须应用当前范围的示例后才能保存；手动方式继续沿用原有保存规则。
  放弃预览不修改配置。保存、复制、重新选择、切换选项卡与主题保留模板配置方式及生成草稿；
  详情收起时禁用其原生表单校验并退出键盘焦点，仍可保存已应用的完整配置。
  UI 草稿 `scanDraft` 仅属于模板内存，不作为正式扫描协议或游戏能力约定。
  扫描坐标结果仅使用经典单片编辑器，预览与已应用布局共用同一张图。
  固定 X，横轴 Z、纵轴 Y，隐藏轴标题、刻度与底部坐标读数，每格一个方块，双箱横占两格。
  接入选区时按完整 Z、Y 跨度初始化列数和行数；在结果上方输入正整数并点“调整画布”生效。
  固定左上格，从右侧和底部增减，仅改变当前草稿尺寸。超出视窗时图内滚动。
  缩小后保留边缘和范围外构件及其占位，扩大时复现。尺寸可撤销，随预览应用、保存与复制保留。
  拖动或用方向键移动构件，落在空格后更新坐标，越界或重叠时归位，可撤销。
  方块侧栏提供箱子、木桶、半砖、楼梯、玻璃、黑紫块和石英块。
  默认图底部三格玻璃两侧各有一块石英楼梯，高边朝内；侧栏半砖和楼梯沿用石英块材质。
  半砖放置时占下半格，右键或 Shift+F10 原格切换上下位置，可撤销，移动和保存保留半砖位置。
  玻璃采用冷灰细边、透明底和斜向反光；石英块为占一格的普通实心方块。
  选中后点击空格放置，或用方向键选格后按回车。
  侧栏可直接拖到空格，拖动预显落点；在占用格或画布外松手、取消手势时不放置。
  点选已有方块后可点“删除方块”或按 Delete 删除。右键楼梯每次顺时针转 90°，四次回到原朝向。
  删除和旋转支持撤销；保存、复制和应用保留删除状态与朝向。
  新增或移动小箱子时，同一行左右贴边的两个小箱子合为双箱；两侧都有候选时先与左侧合并。
  右键双箱或聚焦后按 Shift+F10，可在原地拆为两个独立小箱子；下次移动才重新判断合并。
  添加、移动合并和拆分均可逐步撤销，箱型和占位随坐标草稿保存、复制和应用。
  选区变化后保留只读快照。应用带入预览改动，放弃恢复已应用布局；保存与复制保留独立草稿。
  背景、网格、文字和落点跟随浅绿／深灰主题；主题切换保留编辑位置。刷新恢复内置示例。
  “摆放方块”和“区域与站位”共用画布；标注按绝对坐标保存，移动方块或缩小画布保留标注。
  选择绑定组后拖框绘制识别区或储存区，拖框内平移、拖角点缩放；点双箱两格选为储存范围。
  新组两区须完整；新区使用当前 X，重画已有区保留 X 范围。站位取脚下方块，可关联多个组。
  预览编辑随应用带入，放弃恢复原表单；已应用标注与生成详情共用绑定参数和站位记录。
  构件位置保存于 previewPieces／appliedPieces，预览标注保存于 previewBindings，仅供离线模板。
  位置列表“常用位置”内预置“已扫描分类区（示例）”，作为坐标面板初次选择的资源。
  示例总选区为 (0, 64, 0) 至 (4, 73, 14)，直接包含已应用的扫描草稿、绑定组与脚下站位，
  打开即可查看可编辑的单片坐标结果，无需点击扫描或应用，也不依赖后端；刷新后仍有此内置示例。
  原手动示例继续保留，新建分类区仍默认手动配置，不能将已扫描状态扩散到其他资源。
- 手动配置时，总选区下方常驻储存模式、识别模式、储存方式三个下拉框。
  扫描生成时，相同控件位于应用后的生成详情中。
  三种排除设置收入“识别规则”折叠区，多物品绑定保留独立入口，指定站立位置保留主设置入口。
- 坐标模板的“支撑方块”使用多行文本框，每行填写一个方块 ID，允许填写多种方块，
  不沿用单行输入的 80 字符总长度限制。全局与绑定组独立设置使用相同控件，
  保持主题、右侧对齐和 reveal 动画；Enter 用于换行，不提交表单。
  关闭、收起、保存和复制时保留完整的多行草稿，首次开启独立设置继承全局值。
- “指定站立位置”只放在分类区主设置中，位于多物品绑定之后，
  与“识别区与储存区”入口分开，不放入任何绑定组或独立设置的子菜单。
  主入口支持添加、删除多个站立脚下方块坐标，每条再通过标准多选下拉框选择已配置的
  多个“识别区与储存区”绑定组；区域坐标仍在原绑定组维护，不在站位中重复输入。
  下拉复用模板的选中勾号、键盘操作、向上／向下展开及 200／150ms 动画；
  点选、Enter 或空格切换各项勾选并保持菜单展开，Escape 关闭；摘要显示多选名称或数量。
  组改名即时更新选择名称，独立设置的开关不影响站位；引用中的组须先解除站位绑定才能删除。
  保存时按多选结果写回各组 `standingPlan`，共享同一 `standingId`；重新打开时
  同标识、同坐标合并成一个站位入口，编辑一次同步所有关联组，旧单选记录保持。
  关闭、收起、保存、复制和重新打开保留站位草稿，关闭主开关不丢失各条已选区域。
  旧版组内站位汇总到主入口；已有自定义子区显示为“已保存子区”选项，
  保留原范围，用户另选完整绑定组时才改用该组范围，不静默扩大范围。
  正式字段仍为组内 `standingPlan.enabled` 与 `standingPlan.points`；点内保存 `position`、
  `subregionsEnabled`、`markerArea`、`storageArea`、`expanded`、`standingId`。
  坐标 Y 为脚下方块，执行加 1。
  单片拓展继续平移站位与两个子区，储存子区不能重叠；本次入口修正不改执行流程。
  多站位与多区域绑定已由用户确认并入独立分类基线，普通“指定站立位置”开关初始关闭，
  已保存值保持。删除任务级 `standingSubregionsEnabled`、实验入口、提示及徽标；
  分类无其他实验时隐藏整个实验菜单。调试显示不影响普通站位配置或执行。
  旧全局／组内单站位只在读取时迁移，删除 `specifyStanding`、`standingPosition` 字段和控件。
  独立分类固定使用 `standingPlan`；其他任务的 `standingArea` 使用约定保持。
  完整约定见 `docs/task-flows/category-standing-bindings.md`。
- 坐标模板选择“散货盒子混合储存”后，在其子菜单中显示“散货占比”，
  默认显示 27/54 组，前面的组数可输入 0 到 54 的整数，分母固定为 54 组。
  其他储存方式下收起此项并保留数值；绑定组首次启用独立设置时继承当前全局值，
  之后独立编辑，保存和复制保留数值。正式页面使用全局及组内 `categoryOptions.bulkStacks`
  保存数值，并将生效值写入 `storagePolicy.looseSlots`，接入现有混合储存执行逻辑。
  明确设置散货占比后优先保留配额内散货，只打包超额散货；允许原有或新建的盒子不满，
  不沿用旧的“仅满盒”限制来借走配额内散货凑满盒。已保存配置在读取时采用同一规则。
  旧数据优先读取 `looseSlots`，缺少时按原有 `loosePercent` 换算为 54 格的组数。
- 每个绑定组默认关闭“独立设置”，使用上方全局配置；组内识别区和储存区仍可编辑。
- 开关旁的标签始终为“独立设置”；开关开启表示使用该组配置，关闭表示使用全局配置。
  不随开关状态把标签改为“使用全局设置”，避免混淆开关控制的功能。
- 开启独立设置后，在该组内部展开相同的配置，以及它们已有的相关子选项。
  首次开启时以当前全局值初始化，此后各组独立编辑，不能互相覆盖或反写全局。
- 关闭独立设置时收起配置区并恢复使用全局值，但保留该组已填的独立配置。
  再次开启、保存、复制和重新选择资源时，保留独立设置开关与各组配置值。
- 绑定组展开状态与独立设置开关分离；切换独立设置不得折叠整组或改变区域坐标。
- 全局和组内设置复用控件样式及交互，包含键盘导航、选中勾号和上下展开。
  绑定组常态允许菜单溢出，只有 reveal 动画期间临时裁切，避免子菜单被卡片遮挡。
- 以上规则以坐标模板为准；移植到正式页面时必须接入真实保存与执行逻辑。
- 正式数据用分类区的 `categoryOptions` 保存全局配置，绑定组的 `optionsEnabled` 和
  `categoryOptions` 保存独立开关及草稿；接口和配置文件校验均须支持这些字段。
  实际识别与储存字段由生效配置生成，关闭独立设置时也不得丢弃草稿。
- 单片与选区模式混用时，只拓展生效配置为单片模式的绑定组，选区组保留一次。
- 单片模式使用容器内物品识别时，若识别区与储存区在 X、Z 两轴均无相同范围，
  按转向箱体处理：自动启用 `wholeStorage`，由标记箱对应整片储存区，保留各自尺寸，
  沿整片占地推断方向和步长，不强制压成一格宽。仍有共同轴范围的普通整排布局
  保持原有逐列配对与单格拓展；选区模式不自动改变已有配对方式。
- 总选区通过 `overallArea` 独立保存，不因切换为选区模式或关闭独立设置而缩小或丢失。

### 不可堆叠分类区

- “识别模式”新增“不可堆叠分类”，沿用原下拉与绑定组，不新增资源类型或模式下拉。
- 该模式对整个分类区生效，独立设置继续控制储存和拓展，组内隐藏识别方式。

## 标题栏与开关语义

- 左侧只保留一个小图标和任务名称，不恢复拖动柄或标题前的勾选框。
- 右侧依次放置展开箭头、任务开始／关闭开关，两者独立操作。
- 展开箭头只控制设置区的展开与收起，不改变任务运行状态。
- 任务开关只控制任务开始／关闭，不禁用整个配置区、不改变展开状态、不清空数值。
- 关闭任务后仍能编辑设置；运行状态和配置状态必须分别维护。
- 各子功能自己的开关仅影响该功能；不得与任务运行开关共用状态。
- 保留可访问名称、展开状态、关联区域和任务运行反馈。

## 布局与主题

- 复用项目的浅绿和深灰主题变量，两套主题使用相同结构与交互。
- 模板配色统一维护在 `docs/ui/shared/settings-theme.css`，沿用正式 `workbench.css` 色值。
- 两个选项卡共用一份主题快照；正式主题变化时同步该快照与相关用例。
- 两个选项卡的下拉、开关和设置行悬停共用 `settings-controls.css`；reveal、菜单定位和键盘操作
  共用 `settings-controls.js`。本次只合并模板，正式页面与执行流程尚未接入这些资源。
- 设置行左侧为标签或标签加说明，右侧为控件；同类控件右边缘对齐。
- 设置项名称与分组标题使用主文字色 `--text`，保证清晰度；辅助说明才使用 `--muted`。
- 鼠标悬停时整行高亮，底色随主题变化，文字和控件不因悬停发生位移。
- 高亮只使用一个整行背景层，保留两侧 10px 圆角；子容器不得裁切外扩的高亮，
  行内按钮不再叠加矩形高亮。普通行与“中断与收尾设置”在常态下均无独立底色或卡片。
- 子设置在所属行或分组标题下方排列，必须通过缩进、说明和数值单位表达层级。
  任务模板子选项统一使用 `--sample-child-indent`，常规窗口缩进 20px，
  480px 及以下缩进 10px；分组标题本身不缩进。
  “单个物品最大售卖数量”下的“最大售卖数量”同样按子选项缩进，不得与标题左对齐。
  缩进作用于整条子设置行或内容容器，控件右边缘继续对齐，不使用空格或只移动文字；
  已有子容器缩进时不重复叠加。坐标设置仍按其既有密度与缩进约定实现。
- 不把每个设置行再包进一张独立卡片，不以追加多层 CSS 覆盖代替修改原有规则。
- 控件、标签、说明和弹出菜单在窄窗口下必须完整显示，可换行或改为上下排列。
- 任务条收起后必须保留完整的底部圆角；展开时标题下缘与设置区平整衔接。
  不得通过裁切整个卡片来恢复圆角，以免下拉菜单被截断。
- 左侧高亮条在卡片内用独立装饰层绘制，沿卡片内圆角裁切自身背景。
  不使用加粗的左边框，不形成突出的外轮廓或第二层错位圆角；保留现有内容对齐。

| 普通设置行最小高度 | 82px |

## 主菜单、子菜单与下拉选项

- 主任务设置区、各子设置区都要有展开和收起动画，不能只给子菜单加动画。
- 使用模板的 `reveal` 思路：展开 200ms、收起 150ms，
  缓动为 `cubic-bezier(0.16, 1, 0.3, 1)`。
- 动画过程中平滑改变可见高度与透明度，收起完成后再隐藏内容。
  不在点击时直接用 `hidden` 跳过动画。
- 外层承载可收至零高度的动画，内层承载内容内边距，避免结束时突然跳动。
- 坐标子选项由共用 reveal 在首次使用时包裹无内边距的动画外层，
  高度动画只作用于外层，保留内层设置行的最小高度、内边距和控件尺寸。
  不直接压缩带内边距的设置行，避免收起末段停留在内边距高度后突然消失。
  绑定组的相关间距放入展开内容内部一同收起，不在隐藏时突然移除父级 gap。
- 初次载入不播放展开动画；快速反复点击时取消旧动画，旧回调不得隐藏重新打开的内容。
- 尊重系统减少动态效果的设置；隐藏内容不可通过键盘意外聚焦。
- 下拉选项使用统一主题、用途说明和选中勾号，选中状态与鼠标悬停状态清楚区分。
- 必选资源的“请选择……”只作为未选择时的控件提示，不出现在展开的选项列表中；
  保留底层空值与必填校验，不自动替用户选中第一项。“不指定”等有效空值选项仍保留。
- 选项之间保留 6px 间距；未选中项的悬停底色比选中底色更淡，不连成一整块高亮。
- 下拉菜单不得被卡片裁切，宽度适配窗口；下方空间不足时向上展开。
- 支持方向键导航、Enter／空格选择、Escape 关闭、Tab 离开和点击外部关闭。
  单选选择完成或按 Escape 后，焦点回到触发控件；多选保持菜单展开，
  Tab 关闭菜单后继续正常焦点顺序。
- 折叠、切换策略、关闭子功能或开始／关闭任务时，保留已有配置值。
